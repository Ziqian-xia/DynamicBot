📋 Step-by-Step Qualtrics Integration Guide
1

Prerequisites

  • You know each respondent's 11-digit Census Tract FIPS code (e.g. 37063020100)
  • Your Qualtrics account allows JavaScript in surveys (most do by default)
  • This server is running and accessible via HTTPS from the public internet
2

Set Up Survey Flow — Embedded Data

  • Open your survey → click Survey Flow in the left sidebar
  • Click Add a New Element Here → choose Embedded Data
  • Add field CensusTract — set its value from a URL parameter or a prior question
  • Add field ChatTranscript — leave value empty (the widget will write into it)
  • Optionally add ChatTurns for turn-count analytics
  • Drag this element to the very top of the survey flow, before any question blocks
  • Click Save Flow
3

Pipe the Census Tract into Embedded Data

  • From URL parameter: In the Embedded Data element, set the value of CensusTract to URL Query String Field → parameter name (e.g. ct). Survey link becomes: …?ct=37063020100
  • From a prior question: Use piped text, e.g. ${'{'}q://QID1/ChoiceTextEntryValue{'}'}
  • From a list: Use Contact List or Panel distribution — set CensusTract as a contact field and pipe it in via ${'{'}m://Field/CensusTract{'}'}
4

Create the Chat Question

  • In your survey, click Add Question where you want the chat widget
  • Change question type to Text / Graphic (not Multiple Choice)
  • Clear out any default question text
5

Paste the HTML Code

  • Click the question text area → click the </> source button (or "HTML View")
  • Select all existing content and delete it
  • Paste the HTML code from Step 1 above
  • Click OK / Save
6

Paste the JavaScript Code

  • Click the question's gear icon (⚙) → Add JavaScript
  • You'll see a pre-filled template with Qualtrics.SurveyEngine.addOnload(function(){'{'}...{'}'})
  • Select all and delete the entire content
  • Paste the JS code from Step 2 above
  • Click Save
7

Configure Question Settings

  • In the question settings, set Force Response → OFF
  • The widget programmatically disables the Next button during the chat and re-enables it only after all turns complete — standard Qualtrics force-response will conflict with this
  • Do not add any display logic that hides this question mid-display
8

Test in Preview Mode

  • Click Preview Survey (the ▶ button at the top of the survey editor)
  • Add ?ct=37063020100 to the preview URL to pass a test Census Tract
  • The chat widget should load and show the interviewer's opening message
  • Complete all turns — confirm input is disabled after the last turn and the completion banner appears
  • Finish the survey, then go to Data & Analysis → Response and check the ChatTranscript embedded data field — it should contain the full conversation
9

Analyzing Transcripts After Data Collection

  • Export data as CSV from Data & Analysis
  • The ChatTranscript column contains the full conversation in this format:
[BOT]: Thank you for participating...

[USER]: I had no idea about this project.

[BOT]: That's a common reaction...
  • Import transcripts into qualitative analysis software (NVivo, Atlas.ti, MAXQDA, or even Excel) for coding
  • Use ChatTurns to filter out incomplete conversations
!

Troubleshooting Tips

  • Chat doesn't load: Check browser console for errors. Confirm the server is running and reachable via HTTPS. Qualtrics blocks mixed HTTP/HTTPS requests.
  • Wrong project shown: Confirm CensusTract is set in Survey Flow before the chat question. Use the browser console to check Qualtrics.SurveyEngine.getEmbeddedData('CensusTract').
  • DEFAULT project always shown: Your CT value may have a format mismatch — the server normalizes spaces and dashes, but confirm the exact 11-digit FIPS code matches a key in your study data.
  • Transcript not saved: Confirm the ChatTranscript field exists in your Survey Flow Embedded Data element. The field name is case-sensitive.
  • Next button never appears: The widget enables Next only after all turns complete. If the chat crashes mid-session, reload the preview.
